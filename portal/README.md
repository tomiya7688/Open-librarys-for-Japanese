# 公式サイト・リンクポータル

Python・C++・関連開発ツールの**公式サイト／公式ドキュメント**への入口を、日本語で案内するシンプルな静的ページです。

## 30秒で使う

1. [index.html](./index.html) をブラウザで開く（ローカルでも動作）。
2. サイト名や用途で検索する、または「Python」「C++」「開発ツール」を押して絞り込む。
3. 「公式サイトを見る」「公式ドキュメントを見る」から目的のページへ移動する。

JavaScriptが無効でもリンク一覧の閲覧・クリックは可能です（検索／カテゴリ絞り込みのみJavaScriptが必要）。

インストール、ビルド、サーバー、外部CDN、アカウント登録は不要です。

## 初期掲載の範囲

- Python: 本体、公式ドキュメント、PyPI、pip ドキュメント
- C++: 標準化委員会 WG21、fmt、CMake ドキュメント
- 開発ツール: Git リファレンス

既存の [fmt 日本語ガイド](../Cpp/external/fmt/README.md) へもリンクしています。個別の \`external\` ガイドは維持し、ポータルは「探す入口」に徹します。

初期リンクの公式性・URLは **2026-11-04** に公式のページまたは管理元を照合しました。これは確認日時点の内容であり、その後の稼働・安全性・正確性を保証するものではありません。

## リンク追加・更新の手順

Issueを起票してから編集し、原則 PR でレビューします。

1. **公式性を確認**：プロジェクト自身のドメイン、標準化主体のページ、またはそのプロジェクトが案内する公式リポジトリ・ドキュメントに限定します。検索結果で上位に出るだけの第三者サイト、広告、ミラーは「公式」として扱いません。
2. **説明を日本語で書く**：サイト名より「何をするために見るか」を1〜2文で示し、特定バージョンに依存する文章は極力避けます。
3. **\`index.html\` の \`<article class="site">\` を複製**：\`data-category\` は既存のボタンと一致させ、\`data-keywords\` に日本語・英語の検索語を追加します。
4. **必ずHTTPSリンクにする**：外部リンクは \`target="_blank" rel="noopener noreferrer"\` とし、リンク先・リダイレクト先の正当性を確認します。
5. **確認日を記す**：カードの \`URL確認日\` を実際に確認した日に更新します。既存カードの確認日を、未確認のまま一括更新しません。
6. **重複を避ける**：同じ主要URLは1カードだけ掲載します。公式トップと公式ドキュメントを別カードにする場合は用途の違いを明確にします。
7. **テストする**：以下の静的検証とブラウザでの検索・絞り込み確認を実施します。カードを追加したら件数表示（JavaScript無効時の初期件数）と静的テストの期待件数も更新します。

カテゴリ追加時はフィルタボタンを増やし、同じ文字列を \`data-category\` に使います。サイト数が大きくなるまで、DBやビルドシステムを追加する必要はありません。

## 検証

リポジトリのルートから:

\`\`\`bash
python3 -m unittest portal/test_portal.py
\`\`\`

主に、初期カード件数、カテゴリ、公式URLの重複、外部リンク属性、検索欄の有無、外部スクリプト不使用を確認します。

手動では \`portal/index.html\` をブラウザで開き、次を確認してください。

- 「Python」選択では Python のカードだけを表示
- 「文字列」検索では fmt が見つかる
- 「存在しない文字列」では0件と空状態メッセージを表示
- 検索語を消して「すべて」を選ぶと全カードが再表示
- キーボードの Tab / Enter で検索・フィルタ・リンクを操作可能
- JavaScript無効でもリンク一覧がそのまま見える

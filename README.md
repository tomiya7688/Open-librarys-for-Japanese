# Open libraries for Japanese

さまざまなプログラミング言語のライブラリを、日本語の導入手順・説明とともにまとめるプロジェクトです。

まずは Python と C++ から整備します。

言語に依存しない辞書・データは `Common/` にまとめます。

各言語のライブラリは次の3種類に分けます。

- `original`: このリポジトリで実装するライブラリ
- `imported`: 再配布可能な外部ライブラリを取り込み、日本語ドキュメントを追加するもの
- `external`: ソースコードは取り込まず、公式リンクと日本語の導入手順・使い方をまとめるもの

ライブラリの追加は Issue を起票し、その Issue に紐づけて作業します。
